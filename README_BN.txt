BANGLADESH CITY LIFE — Android starter project v2
================================================

নতুন যোগ হয়েছে:
- নিজস্ব গেম আইকন (mipmap density variants)
- Android splash background/theme
- গেমের ভেতরে Main Menu ও Start button
- Offline HTML asset WebView-তে লোড হয়
- PROMO_CONCEPT.png: ধারণামূলক প্রচার-ছবি, আসল gameplay screenshot নয়

Build: Android SDK ও Gradle সহ Android build environment প্রয়োজন।
এই ZIP সরাসরি ইনস্টলযোগ্য APK/AAB নয়।

সীমাবদ্ধতা: বর্তমান গেমটি 2D prototype; 3D Bangladesh open-world নয়।
Play Store প্রকাশের আগে পরীক্ষা, privacy/data safety, store listing, target API ও Play policy মেনে build করতে হবে।
Developer account account-holder-এর বয়স ও Google Play-এর বর্তমান নিয়ম মেনে করতে হবে; অপ্রাপ্তবয়স্ক হলে অভিভাবককে দায়িত্ব নিতে হবে।
